# 🚀 Python Generative AI & LangChain Internship

Welcome to my **Python Generative AI & LangChain Internship Repository!**

This repository contains four hands-on projects developed as part of my internship, focusing on Generative AI, Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), AI agents, and structured data extraction.

The projects demonstrate practical implementations of modern AI technologies, combining Python, LLM integrations, LangChain-based workflows, and application development.

---

## 📂 Repository Contents

This repository consists of four major projects:

### 1. Q&A Assistant with RAG
**Folder:** `Q&A_Assistant_Rag/`

A Retrieval-Augmented Generation (RAG) based question-answering system that enables users to retrieve relevant information from custom documents and generate context-aware responses.

**Key Concepts:**
- Retrieval-Augmented Generation (RAG)
- Document processing and text chunking
- Text embeddings
- Vector database and similarity search
- Context-aware question answering
- LLM integration

### 2. Full-Stack AI Chatbot
**Folder:** `fullstack_AIchatbot/`

An AI-powered chatbot application that integrates a language model with a user-facing application to provide interactive conversational experiences.

**Key Concepts:**
- Generative AI
- Large Language Models (LLMs)
- AI-powered conversations
- Backend and frontend integration
- API integration
- Full-stack application development

### 3. Multi-Tool AI Agent
**Folder:** `multi_tool_ai_agent/`

An intelligent AI agent designed to interact with multiple tools and execute tasks based on user instructions.

**Key Concepts:**
- AI Agents
- LangChain
- Tool Calling and Function Calling
- Agent orchestration
- LLM-powered decision making
- Multi-tool integration

### 4. Structured LLM JSON Extractor
**Folder:** `structured_llm_extractor_json/`

A structured information extraction application that converts unstructured text into organized JSON output using LLMs and data validation.

**Key Concepts:**
- Structured Prompt Engineering
- OpenAI and Google Gemini integration
- Pydantic validation
- JSON extraction
- Schema-based data validation
- Structured LLM outputs

## ⚙️ Installation & Setup

### Prerequisites

Make sure you have the following installed:

- Python 3.10 or later (depending on project requirements)
- Git
- Visual Studio Code
- Required API credentials for the relevant AI services

### Step 1: Clone the Repository

```bash
git clone https://github.com/hifzaaqleem/Datheon_Python_Generative_AI_-_LangChain_Internship.git
```

### Step 2: Navigate to the Repository

```bash
cd Datheon_Python_Generative_AI_-_LangChain_Internship
```

### Step 3: Open a Project Folder

Choose the project you want to run.

```bash
cd Q&A_Assistant_Rag
```

### Step 4: Create a Virtual Environment

```bash
python -m venv venv
```

Activate it:

**Windows:**
```bash
venv\Scripts\activate
```

**macOS/Linux:**
```bash
source venv/bin/activate
```

### Step 5: Install Dependencies

If the selected project contains a `requirements.txt` file:

```bash
pip install -r requirements.txt
```

### Step 6: Configure Environment Variables

Create a `.env` file inside the relevant project folder and add the required API credentials.

Example:

```env
GOOGLE_API_KEY=your_google_api_key
OPENAI_API_KEY=your_openai_api_key
```

Use only the variables required by that project.

### Step 7: Run the Application

Follow the individual project's instructions and execute its corresponding entry-point file.

## 🔐 Security & Best Practices

- API keys and credentials must never be committed to GitHub.
- Keep `.env` files excluded using `.gitignore`.
- Use `.env.example` to document required environment variables.
- Never expose private service account credentials.
- Maintain separate virtual environments for individual projects.
- Follow proper Git version-control practices.
